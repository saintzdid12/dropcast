# Included Clutch data

The first-run show uses the first 100 teams from [Squads Victory Cup, NA West finals, session 4](https://clutchfn.com/fortnite/squads-victory-cup-naw-s43/event-2-round-2), captured from Clutch's public standings on November 24, 2026.

The source URL and capture time are stored in `public/clutch-snapshot.js`. Points, matches, wins, eliminations, and reported places come from that page. The default featured squad is Acorn, Peterbot, Khanada, and XSET FAХUTY1X: place 13, 3 matches, 1 win, 14 eliminations, 100 points.

This is a saved snapshot, not a live API connection. Later pages of the event's standings are not included. Team colors are neutral placeholders. The qualifying place is an operator setting, not a claim about this event's rules. Estimated qual starts unset.

Editing team results changes the source label to indicate manual edits. **Show files > Load Clutch snapshot** restores the included data after confirmation. Existing saved shows are not automatically replaced on upgrade.

The preview backdrop is cropped from Clutch's [public overlay screenshot](https://github.com/saintzdid12/clutch-data-api/blob/main/assets/overlay.webp). It appears only in the operator preview. OBS pages remain transparent and do not include the backdrop. Fortnite imagery belongs to Epic Games; the project's MIT license applies to its code.
